# Эталонные прогоны

Здесь лежат CSV автоматчей, с которыми сравниваются результаты после каждого
этапа (требование ROADMAP).

Воспроизвести любой из них:

```
./gradlew lwjgl3:run -Pargs="--sim 100 --seed 1 --out ../sim-results/check.csv"
```

Прогон детерминирован: одинаковый сид даёт побайтово одинаковый CSV.

## stage0-seed1-100matches.csv

Состояние до любых изменений в правилах игры. 100 партий, сид 1, 5 фракций,
средняя карта, сложность balancer, дипломатия включена.

| Показатель | Значение |
|---|---|
| Время прогона | 2.0 с |
| Партий не доиграно | 0 |
| Длительность, медиана | 55 ходов |
| Длительность, максимум | 125 ходов |
| Доля карты у лидера, среднее | 0.349 |
| Объявлений войны за партию | 9.1 |
| Сделок за партию | 36.4 |
| Пиковая казна лидера, медиана | 442 |
| Пиковая казна лидера, максимум | 7272 |

Победы распределены ровно (17–24 на фракцию), позиционного перекоса нет.

Медиана пиковой казны 442 при максимуме 7272 — это численное подтверждение
проблемы 2 из SPEC: снежный ком. Этап 2 требует уронить максимальную казну
лидера минимум вдвое, отсчитывать нужно отсюда.
